This repository contains configurations for various services deployed using Docker and Docker Compose.

## List of Services

- [01. Traefik](01.%20traefik/) — Reverse proxy with Let's Encrypt support.
- [02. Watchtower](02.%20watchtower/) — Automatic Docker container updates.
- [03. Harbor](03.%20harbor/) — Private Docker registry.
- [04. Headscale](04.%20headscale/) — Self-hosted Tailscale control server (Open Source).
- [05. Robots-disallow](05.%20robots-disallow/) — Service for serving `robots.txt` with `Disallow: /`.
- [06. OpenSearch](06.%20opensearch/) — Search engine alternative to Elasticsearch.

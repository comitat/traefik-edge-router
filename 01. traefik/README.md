### 🛠️ Traefik Infrastructure  

Простая и надёжная инфраструктура на базе Traefik v3 в качестве обратного прокси и шлюза для всех ваших сервисов.  
  
🔐 Автоматический HTTPS через Let's Encrypt  
🛡️ Защищённый доступ к дашбордам с аутентификацией  
🌐 Все сервисы доступны по домену  
➕ Простое масштабирование — легко добавлять новые сервисы  

📁 Структура проекта  
```
.
├── docker-compose.yml     # Основные сервисы: Traefik, Portainer
├── .htpasswd              # Файл с учётными данными для Basic Auth (в .gitignore)
├── letsencrypt/           # Том для хранения сертификатов ACME (создаётся автоматически)
└── README.md              # Документация
```  

#### 🚀 Быстрый запуск

##### 1. Установите зависимости  

Убедитесь, что у вас установлены:  

- Docker
- Docker Compose
##### 2. Настройте домен  

Замените все вхождения example.domain.com на ваш реальный домен:  

- В docker-compose.yml
- В конфигурации маршрутов сервисов 

##### 3. Создайте файл .htpasswd для доступа к дашборду

Установите htpasswd, если он ещё не установлен:  

```
sudo apt update && sudo apt install apache2-utils -y
```

Создайте файл с логином и паролем (например, для пользователя admin):  

```
htpasswd -c .htpasswd admin
```

##### 4. Запуск Traefik  
Сначала создаем сеть  
```  
docker network create traefik  
``` 
После этого запускаем докер компоуз  
```   
docker compose up -d  
```  

##### Доступ к дашборду Traefik
После запуска дашборд будет доступен по адресу: 
https://traefik.example.domain.com

Позволяет управлять контейнерами, образами, томами, сетями и стеками через удобный графический интерфейс — без командной строки.  
- Легко запускать/останавливать контейнеры

- Настраивать всё визуально, особенно удобно на VPS или сервере

##### Bonus  
##### 🧩 Сервис: traefik-certs-dumper   
Traefik хранит SSL-сертификаты в формате acme.json.  
Другие сервисы (например, Postfix, Dovecot, Rundeck, Nginx) не могут читать этот файл, но могут работать с обычными PEM-файлами.  

traefik-certs-dumper решает эту проблему:  
  
✅ Автоматически извлекает сертификаты из acme.json  
🔄 Конвертирует их в стандартные PEM-файлы  
📁 Сохраняет в виде:  
- cert.pem — сертификат.  
- key.pem — приватный ключ  
 Теперь вы можете использовать те же сертификаты в других сервисах без дублирования выпуска от Let's Encrypt.

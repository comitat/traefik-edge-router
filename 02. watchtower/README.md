### Watchtower 
**Watchtower** — это контейнер, который **автоматически проверяет и обновляет** ваши Docker-образы до последних версий.  
  
#### Что делает:  
- Каждые **6 часов** (`21600` сек) проверяет, есть ли новые версии образов. 
- Автоматически обновляет контейнеры при наличии новых образов. 
- Удаляет старые образы (`cleanup: true`)  
- Поддерживает откат при ошибках (`rollback: true`)  
- Отправляет подробные уведомления в **Telegram**  
  
**Формат Chat ID**:  
-  Для личного чата: `channels=123456789`
-  Для группы/канала: `channels=-100123456789`

# Self-Hosted Writing & Media Stack

Этот проект разворачивает локальный, полностью контролируемый стек для письма, публикаций и управления медиафайлами.  
Ничего лишнего — только то, что нужно для продуктивной работы: чистое письмо, мгновенная загрузка изображений и удобные инструменты.

---

## 🧩 Компоненты

### 1. [WriteFreely](https://writefreely.org/) — Минималистичный блог-движок
> *«Сделано для письма»*

- ✍️ Идеальная среда для фокуса: без отвлекающих лент, уведомлений и "лайков".
- 🌐 Поддержка **ActivityPub**: твой блог доступен в фидиверсе (Mastodon, Pleroma и др.).
- 💾 Автосохранение, черновики, приватные записи, парольная защита.
- 🚀 Написан на Go — работает быстро даже на слабых серверах (например, Raspberry Pi).

🔧 **Как войти:**  
При первом запуске открой `https://write.domain.com`, зарегистрируй аккаунт.  
Первый пользователь становится **администратором**.

---

### 2. [Picsur](https://github.com/CaramelFur/Picsur) — Self-hosted хостинг изображений

- 🖼 Загружай скриншоты и картинки напрямую из ShareX или браузера.
- 🔐 Защита панели настроек паролем (по умолчанию: `admin` / `picsur`).
- 🔄 Полная интеграция с **ShareX** — один клик и ссылка уже в буфере обмена.
- 📁 Хранит файлы локально, без зависимости от третьих сторон.

🔧 **Как войти:**  
Зайди в `https://picsur.domain.com`  
Login: admin  
Password: picsur  
  
#### 🔗 Интеграция с ShareX  
  
В Picsur перейди в Settings → ShareX  
Нажми "Generate Config", скачай .sxcu-файл. 
В ShareX: Tools → Import → выбери скачанный файл  
 ✅ Теперь при Print Screen → Ctrl + V — скриншот автоматически загружается и копируется ссылка!  

---

### 3. [IT Tools](https://github.com/CorentinTh/it-tools) — Универсальный веб-инструментарий

- 🔤 Конвертеры: Base64, JSON, YAML, XML, JWT, Regex, QR-коды и многое другое.
- 🛠 Не требует интернета — всё работает в браузере.

🔧 **Как использовать:**  
Просто зайди на `https://tools.domain.com` — никакой авторизации не нужно.

---

## 🌐 Архитектура

Стек использует Docker + Traefik для:
- Автоматического HTTPS (Let's Encrypt)
- Роутинга по поддоменам (`write.`, `picsur.`, `tools.`)
- Централизованного управления доступом

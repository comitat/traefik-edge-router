# Headscale — Локальный Tailscale-сервер  
  
Этот проект запускает **локальный Tailscale-совместимый сервер** с помощью `headscale`  
  
- Позволяет создавать **Mesh-сети** между серверами, контейнерами, ноутбуками и IoT-устройствами  
- Работает с **официальным Tailscale CLI-клиентом**  
- Полностью контролируется вами — **никаких данных в облаке Tailscale**  
  
## Сервисы в `docker-compose.yml`  
 1. `headscale` (основной сервер)  
- **Назначение**: Управление сетью, аутентификация, выдача IP  
- **Доступ**: Через API (порт 8080 внутри Docker)  
- **Используется клиентами Tailscale**  
 2. `headscale-admin`  
- Веб-интерфейс для управления Headscale  
- Адрес: `https://headscale.yourdomain.com/admin`  
- Можно просматривать узлы, генерировать ключи, управлять политиками  
    
  ---  
Bonus - headscale-ui  
Более легковестный и минималистчный веб-интерфейс для управления Headscale  
Адрес: `https://headscale.yourdomain.com/web`
